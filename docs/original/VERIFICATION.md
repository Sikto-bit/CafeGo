## Пройденные автоматические тесты

1. `TestSchemaSeedAndPersistence`: схема, повторная инициализация, внешние
   ключи, запрет удаления занятой категории, сохранение после повторного открытия.
2. `TestAuthenticationAndSecurity`: регистрация, bcrypt, роль client, вход/выход,
   повторы логина без учёта регистра, запрет всех административных действий,
   CSRF, изоляция токенов разных сессий, cookie-флаги и CSP.
3. `TestCRUDCartAndOrders`: создание/чтение/изменение/удаление категорий и блюд,
   валидация, фильтр меню, экранирование HTML, изменение количества и суммы,
   чужая корзина и история, цена на момент заказа, допустимые статусы,
   сохранение позиций заказа после удаления блюда и категории.
4. `TestConcurrentCheckoutAndExpiredSession`: два одновременных оформления
   создают только один заказ; истёкшая сессия не меняет корзину.
5. `TestPrices`: копейки, точка/запятая, границы, отрицательные значения,
   слишком точные и некорректные цены.
6. `TestCheckoutRollback`: искусственная ошибка вставки позиции заказа
   откатывает весь заказ и сохраняет корзину; повтор после исправления успешен.

Тесты используют настоящую SQLite во временных каталогах, полный HTTP Handler,
`http.Client`, CookieJar и тестовый `RoundTripper` с `httptest.ResponseRecorder`.
Проверки не затрагивают базу пользователя и не требуют сетевых сокетов.
Сообщение `constraint failed: test failure` во время последнего теста ожидаемо:
это специально установленный SQLite-trigger для проверки отката.

## Ограничения проверки

Первоначальные попытки скачивания из рабочего окружения остановились на DNS;
после установки Go и загрузки зависимостей пользователем сборка стала доступна.
Первоначальные HTTP-тесты через `httptest.Server` не могли подключиться к
localhost из-за сетевой изоляции, поэтому заменён только тестовый транспорт.

Встроенный браузер вернул `ERR_CONNECTION_TIMED_OUT` при открытии запущенного
сервера, а управление Firefox остановлено политикой инструмента
(`browser URL policy enforcement is not yet supported for the current Windows browser`).
Поэтому визуальная проверка на широком и мобильном экране и соединение
браузер → локальный сервер не подтверждены. Успех рендеринга шаблонов и
пользовательских сценариев подтверждён HTTP-тестами. Сам HTTP listener успешно
запущен; в обычном пользовательском терминале запуск описан в README.

Команды для повторения проверки:

```powershell
go mod tidy
go test -count=1 -v ./...
go vet ./...
go build -o cafego.exe ./cmd/cafego
git log --oneline --reverse
git status --short
```
