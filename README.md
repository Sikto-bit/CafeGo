# CafeGo — этап 03

> Этап реконструирован из готового CafeGo. Исходная хронология разработки неизвестна.

## Реализовано

Go-сервер с общим макетом, встроенными шаблонами и CSS. Меню использует явно обозначенные демонстрационные данные и фильтр по категориям.

## Доступность функций

SQLite, авторизация, управление каталогом, корзина и заказы.

## Запуск

Распакуйте ZIP в отдельную папку и откройте папку `CafeGo/`.

Потребуется Go 1.23 или новее. Откройте терминал в папке с `go.mod`.

Запустите сервер.

```powershell
go run ./cmd/cafego
```

Откройте <http://127.0.0.1:8080/>. Для остановки нажмите Ctrl+C.

## Проверка

```powershell
go test ./...
go vet ./...
```
