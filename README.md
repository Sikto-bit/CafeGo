# CafeGo — этап 01

> Этап реконструирован из готового CafeGo. Исходная хронология разработки неизвестна.

## Реализовано

Самостоятельные HTML-страницы меню, входа, регистрации, корзины, истории заказов и административного интерфейса с демонстрационными данными.

## Доступность функций

CSS, Go, SQLite и все действия с данными. Поля и кнопки показаны для демонстрации.

## Запуск

Распакуйте ZIP в отдельную папку и откройте папку `CafeGo/`.

Откройте `index.html` в браузере. Остальные страницы доступны по ссылкам в меню. Сервер и зависимости не требуются.
