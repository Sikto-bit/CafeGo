# CafeGo — этап 06

> Этап реконструирован из готового CafeGo. Исходная хронология разработки неизвестна.

## Реализовано

Администратор может создавать, изменять и удалять категории и блюда. Сервер проверяет права, поля формы и целостность связей.

## Доступность функций

Корзина, заказы и сводка.

## Запуск

Распакуйте ZIP в отдельную папку и откройте папку `CafeGo/`.

Потребуется Go 1.23 или новее. Откройте терминал в папке с `go.mod`.

При первом скачивании Go-зависимостей потребуется интернет. SQLite встроена в приложение.

Перед первым запуском создайте администратора, если нужен доступ к управлению.

```powershell
go run ./cmd/cafego -db ./data/cafego-local.db -create-admin admin
```

Введите свой пароль длиной 10–72 байта и нажмите Enter. Ввод виден в терминале.
При повторном запуске приложения создавать администратора заново не нужно.
Встроенных аккаунтов нет.

Запустите сервер.

```powershell
go run ./cmd/cafego -db ./data/cafego-local.db
```

Откройте <http://127.0.0.1:8080/>. Для остановки нажмите Ctrl+C.

При первом запуске сервера база и меню создаются автоматически. Повторные запуски используют ту же БД.
Без `-db` путь вычисляется относительно исполняемого файла, который при `go run` создаётся во временной папке.

### Скрипты Windows

Сначала соберите исполняемый файл в корне проекта.

```powershell
go build -o cafego.exe ./cmd/cafego
```

Для создания администратора откройте `CREATE_ADMIN.cmd` и задайте пароль. Затем запустите `START.cmd`.
Скрипты используют путь `data/cafego-local.db` рядом с `cafego.exe`.
